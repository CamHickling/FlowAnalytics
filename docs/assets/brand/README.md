# FlowAnalytics brand assets

Each asset is provided as PNG and SVG. Use the PNG on GitHub; the SVG files embed
raster images and are several times larger.

| Asset | Size | Use |
| --- | --- | --- |
| `readme-banner-dark` / `readme-banner-light` | 1280 × 320 | README header (switched by GitHub theme) |
| `flowanalytics-logo-dark` / `flowanalytics-logo-light` | 957 × 160 | Horizontal logo for docs and slides |
| `flowanalytics-mark-512` / `flowanalytics-mark-1024` | square | Logo mark on its own |
| `social-preview` | 1280 × 640 | GitHub **Settings → Social preview** |
| `avatar` | 512 × 512 | Organization or profile picture |
| `favicon-32` / `favicon-180` / `favicon.svg` | 32, 180, 64 | Browser and touch icons for a docs site |

Palette (sampled from the artwork): background navy `#071A33`, wordmark navy `#0A2F6B`, ring blue `#1876BE`, highlight `#8EC5F0`, ice `#F3F8FE`.
